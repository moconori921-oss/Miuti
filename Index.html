A10 Duoの原則

最重要：Duo専用の大コンボを完成させることより、まず「二人とも単独で機能する強いデッキ」を作る。Duoカードはその上に載せる増幅器。

勝率を落とす4要因

  1. 相方依存の未完成デッキ
  2. Act1から二人ともスケーリング・支援寄り
  3. 弱体・脆弱・筋力低下・ポーションを共有資産として使えていない
  4. A10二連ボスに対し立ち上がりが遅い

強いDuoの共通点

  • 各自に自己防御がある
  • Act1から火力を出せる
  • 共有デバフを切らさない
  • 特定Rareがなくても動く
  • 1～2周目に勝ち筋が始動する
Act1床を作る
Act2敵別回答を揃える
Act3二連ボスを2回立ち上げる
A10最大出力より最低出力

A10で特に重い要素

  • A3：ゴールド獲得量低下
  • A4：ポーションスロット減少
  • A5：呪い追加
  • A6：ショップ削除費用上昇
  • A7：Rare・強化済みカード出現率低下
  • A8/A9：敵耐久・攻撃激化
  • A10：Act3最後に異なるボスを2体連続で戦う
第一ボスでPower・Strength・Dexterity等の戦闘状態はリセットされるが、HPとポーションは持ち越す。したがって「一戦だけ完成すれば強い」では足りない。

基本コンボ

  1. 身震い → 挟撃 → 大型Attack：脆弱×挟撃でアイクラの一撃を極端に増幅。
  2. 金切り声 → アイクラ完全攻撃：敵多段をまとめて弱め、アイクラの防御エナジーを攻撃へ変換。
  3. 不快感 → 長期戦：サイレントが敵DPSそのものを下げ、アイクラの筋力・廃棄セットアップ時間を作る。
  4. 用意周到＋挟撃：挟撃をアイクラの鬼火・脳天割り等が来るまで保持。
  5. タッグチーム → 大型Attack：小Attackで消費しない。
罠：アイクラがPower/廃棄完成待ち、サイレントもFootwork/毒Power完成待ちになると、Turn1～2に敵HPが減らずA10で破綻する。

ダブルアイクラ

最も再現性が高いDuoの一つ。二人で脆弱を共有し、高効率Attackを押し付ける。

評価が上がるカード

  • 身震い：一人が脆弱担当へ寄せ、もう一人はAttack密度を上げてもよい。
  • ごろつき：二人で弱体を積めるため火力上限が高い。
  • ポンメルストライク：ダブルアイクラ最大の弱点であるデッキ操作不足を補う。
  • 供物：両者で強いが、二人とも自傷過多にしない。
  • 衝撃波（無色）：不足する脱力を一枚で補う最重要候補。

おすすめ役割分担

A：テンポ

身震い、ポンメルストライク、旋風刃、ごろつき、脳天割り、供物、瀉血。

B：制御＋後半

身震い、アッパーカット、衝撃波、焦熱の契約、無痛、闇の抱擁、鬼火、威圧。

避ける：二人ともバリケード、二人とも廃棄Power先行、二人とも自傷型。

ダブルサイレント

Act1火力不足が最大の壁。そこを越えると、筋力低下と毒の共有で非常に強い。

重要カード

  • 金切り声：二人分の被害をまとめて軽減。2枚以上でも価値が高い。
  • 不快感：長期戦の敵火力を恒久的に壊す。
  • 有毒ガス＋促進剤：毒付与担当と増幅担当を分けられる。
  • 挟撃：相方がナイフ・多段Attack型なら高評価。二人とも毒特化なら優先度低下。

役割分担

A：前半・Attack寄り

リーディングストライク、五月雨ダガー、暴露、ナイフ、金切り声、バックフリップ。

B：制御・長期戦

金切り声、不快感、足払い、有毒ガス、促進剤、用意周到。

Act1では防御を取りすぎない。完璧に守れても敵が死なない構成が最も危険。強い無色Attackの購入価値も高い。

アイクラ＋リージェント

役割：アイクラがAct1の火力・脆弱を担当し、リージェントが脱力・星・防御・後半スケーリングを担当する。

基本連携

  1. 落星 → 身震い → 全力Attack：脱力＋弱体＋脆弱を二人で完成。
  2. リージェント低コスト防御 → アイクラ完全攻撃：星を第二エナジーとして使う。
  3. 星座 → アイクラ：ドロー＋エナジー＋Blockで大技ターンを成立。
  4. 教示 → アイクラの鬼火/供物/身震い：必要札を直接サーチ。
  5. 策謀 → 次ターン爆発：二人とも追加ドローでPower＋Attack展開。
  6. お前を信じる → リージェント：星はあるが通常エナジーが足りないターンを解決。
  7. ハンマータイム＋鍛造：鍛造源が十分ある場合のみ条件S。
  8. リージェント弱体 → ごろつき：弱体スタックをアイクラ火力へ変換。

最大の罠

アイクラが闇の抱擁・無痛・悪魔化、リージェントが武器庫・スペクトラムシフト・虚無化、と両者セットアップ型になること。Turn1に敵HPが減らない。

星の収支ルール

「星カードの枚数」ではなく「山札一周で何スター作れて何スター使うか」で考える。生成5しかないのに反射3＋粒子障壁3＋星霊の波動3を全部使う想定は破綻している。

ショップ・ゴールド管理

ショップ＝削除所ではない。「今できないこと」をゴールドで解決し、余剰金で削除してデッキを洗練する。

購入優先順位

  1. ランを直接救うレリック
  2. 不足機能を埋める強カード
  3. 次の危険戦用ポーション
  4. 強い無色カード
  5. カード削除
  6. 微妙なカード/レリック

持ち金の目安

所持金判断
～100Gルート上なら見るが、積極的ショップ目的には弱い。
150G前後強アンコモン＋ポーション等が可能。
200～250G最も入りたい。レリック/Rare/無色/削除を比較できる。
300G以上レリック＋カードなど複数購入可能。無駄買いは避ける。

削除

A10では削除費用が100→150→200→250…と重くなる。1回目は普通、2回目は慎重、3回目以降は特殊理由がない限り低優先。

  • アイアンクラッド：焦熱の契約・セカンドウィンド・鬼火で戦闘中に不要札処理が可能なので削除優先度低め。
  • サイレント：ストライク削除価値は比較的高いが、金切り声などの即戦力があるならカード購入優先。
  • リージェント：専制・突撃せよ！により不要札を処理できるなら削除を急がない。

Act別

  • Act1前半：削除しない。強カード＋ポーション。
  • Act1後半：200G以上ならショップ価値高。何もなければ初回削除。
  • Act2：150～250Gで入り、デッキの弱点を解決。
  • Act3：二連ボス用にゴールドを戦闘力へ変換。最終ショップはほぼ使い切る。

要注意エリート

Act1：繁茂

ビャードニス

火力チェック。長引くほど筋力が増え多段が危険。3～4ターンで倒す。

古の偶像

少数高出力カード。小さいカード連打より大型Attack。Turn3以降も30/turn程度なら避ける。

寄生カエル

AoE要求。本体後の小型4体を旋風刃/星霊の波動等で早期処理。

Act1：地下水路

テラーウツボ

HP閾値を跨いだ後のスタンターンで殺し切る。弱いタイミングで閾値を踏まない。

蠢く群生体

1ターンの削り上限あり。大型バーストの無駄撃ち禁止。ドロー・状態異常処理が重要。

幻影蟲

均等削りせず4→3→2→1と集中処理。単発大打点が有利。

Act2

デシミリピード

AoEを散らさず同じセグメントへ集中。単体高打点ペアなら比較的得意。

エントマンサー

最重要警戒。小Attack連打が山札を汚す。大型Attack＋焦熱の契約/専制などの状態異常処理。

感染プリズム

毎ターン最初にAttackして追加エナジーを得る。Attack→Block/Powerの順。

Act3

メカナイト

最高危険。Artifactを安価に剥がせないデバフ依存デッキは避ける。

騎士3体

Power依存ならマギ・ナイト優先。敵数を早く減らす。

ソウルネクサス

Turn1大打点への耐性チェック。初手事故でも処理できるかを踏む前に確認。

GO / NO-GO

GO

  • 最悪のエリート候補への回答がある
  • 二人とも最低50～60%程度HP
  • ポーション1本以上を使ってよい
  • エリート後に休憩/ショップ/逃げ道
  • 通常引きでも火力が出る

NO-GO

  • 「多分勝てる」だけで敵候補を把握していない
  • 片方が完全に相方依存
  • Act2エントマンサーに小Attackしかない
  • Act3メカナイトのArtifactを剥がせない
  • ポーションを絶対温存したい
  • エリート後のHPが二連ボスへ響く
HPは現在値ではなく「エリート後」で見る。さらにエリート後3マス（休憩、ショップ、通常戦、ボス）まで含めて判断する。

Duoのターン進行

カードを1枚も使う前に、毎ターンこれだけ共有する。

例：
A：最大42ダメージ、18Block、身震いあり。
B：31ダメージ、脱力あり、星座あり。
順番：Artifact剥がし → 身震い → Duo倍率 → 大技 → 残り処理。
  1. 最大ダメージ
  2. 最大Block
  3. 弱体・脆弱・筋力低下
  4. 挟撃・ノックダウン・タッグチーム等
  5. ポーション
  6. 保留・エセリアル・手札上限
  7. 今ターン倒す敵
典型事故：Artifactを剥がす前に本命デバフ、挟撃前にAttack、タッグチームをStrikeで消費、相方の手札満杯で全体ドロー。

A10 Duo 最終チェックリスト

Act3突入時

  • 二人とも自己防御可能
  • 弱体または筋力低下を安定供給
  • 脆弱を安定供給
  • 状態異常処理
  • Attack回数要求への回答
  • 最初の山札一周でエンジン始動

二連ボス前

  • 第一ボス用と第二ボス用ポーションを区別
  • 第一ボスを低損害で倒せる
  • セットアップに5ターンかからない
  • 初手事故でも致命傷を受けない
  • 最後のショップでゴールドを戦闘力へ変換済み
最後に：特殊コンボは「二つの普通に強いデッキ」の上に乗せる。A10 Duoで勝つための基本は、各自が機能し、共有デバフとDuo倍率を必要なターンだけ集中させること。
