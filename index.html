1. A10 Duoの原則

勝ち筋Act別二連ボス思考
最重要：Duo専用の大コンボより、まず二人とも単独で動く強いデッキを作る。Duoカードは増幅器。

負け筋

  1. 相方依存の未完成デッキ
  2. 二人ともセットアップ型
  3. 共有デバフを活かせていない
  4. 第一ボスでHPを使い切る

勝つデッキ

  • 各自で自己防御可能
  • Act1から火力あり
  • 1～2周目にエンジン始動
  • 初手事故への回答あり
  • 第一ボスを低損害で倒せる
Act1床を作る
Act2敵別回答
Act3初動を磨く
A10二回立ち上げる
二連ボスでは最大出力より再現性。Powerを3～4枚置かないと動かない構成、第一ボスに30～40HP払う構成は第二戦で破綻しやすい。

5. リージェント

理想デッキ星経済カード評価コンボ罠

理想デッキ：星ミッドレンジ

20～25枚程度なら、通常Attack3～5、星生成3～5、星消費2～4、Block4～6、脱力/弱体1～3、ドロー/山札操作3～5、Power1～3が目安。

目標：毎ターン15～25Blockしながら20～30ダメージ進める。派手な100ダメージコンボよりA10ではこの地味な再現性が強い。

星経済

  • 星生成≧星消費にする。
  • 「カード枚数」ではなく山札一周で何スター作れて何スター使うかで計算。
  • Blockを星で処理し、通常エナジーをAttack/Powerへ回す。

6. ペア別運用

アイクラ＋サイレントアイクラ＋リージェントダブルサイレントダブルアイクラ

アイクラ＋サイレント

Silentが敵を止め、Cladが殺す。

  • サイレント：金切り声/不快感/用意周到/挟撃
  • アイクラ：身震い/供物/ポンメル/鬼火

アイクラ＋リージェント

Regentが自分を安く守って盤面を安定させ、Cladが殺す。

  • リージェント：落星/光の集約/反射/専制
  • アイクラ：脆弱＋frontload

ダブルサイレント

一人frontload、一人制御/毒。二人とも防御過多にしない。

ダブルアイクラ

一人テンポ、一人制御/廃棄。脱力不足を無色やアッパーカットで補う。

8. ショップ・ゴールド管理

優先順位所持金削除
ショップ＝削除所ではない。まず不足機能を買い、余った金で削除。
  1. ランを直接救うレリック
  2. 不足機能を埋めるカード
  3. 次の危険戦用ポーション
  4. 強い無色
  5. 削除

所持金

  • ～100G：積極的ショップ目的には弱い
  • 150G：強アンコモン＋ポーション
  • 200～250G：最も入りたい
  • 300G以上：複数購入可能

削除

A10では100→150→200→250…と重い。1回目は普通、2回目慎重、3回目以降低優先。

12. A10二連ボス対策

目標アイクラサイレントリージェント
第一ボスは「勝てるか」ではなく「HP15前後以内の損失で倒せるか」で考える。

共通チェック

  1. Turn1にPowerしかできない構成になっていないか
  2. 40ダメージ予告への回答があるか
  3. 4～6ターン程度で第一ボスを終えられるか
  4. 第二ボスTurn1からまた動けるか

アイアンクラッド

Act3では新しいAttackより供物・焦熱の契約・不動・受け流しを優先し、初動とHP保全を強化。

サイレント

追加毒より金切り声・不快感・用意周到・ドロー。第一戦でHPを残す。

リージェント

派手な星消費大技より専制・反射・光の集約・フォトンカット・星の外套で毎戦同じように動ける形を作る。

13. Duoターン進行

共有順番

毎ターン最初に共有

  1. 最大ダメージ
  2. 最大Block
  3. Weak/脆弱/筋力低下
  4. Duo倍率
  5. ポーション
  6. 保留/エセリアル/手札上限

基本順番

Artifact剥がし
→ 弱体 / 脆弱
→ 挟撃 / ノックダウン / タッグチーム
→ 主力Attack
→ 残り処理
典型事故：本命デバフ前にArtifactを剥がしていない、挟撃前にAttack、タッグチームをStrikeで消費、相方手札満杯で全体ドロー。
